計算方式與 iPhone 開啟說明

下載本 HTML 後，需在可執行 JavaScript 的瀏覽器環境開啟。iPhone 的「檔案」或 ChatGPT 預覽可能只顯示內容；若按鈕無反應，代表目前預覽未執行程式。這是單一 HTML 檔，無外部套件；在相容環境開啟後可離線計算。

淨價差＝（賣出價－買回價）×操作股數－賣出手續費－買進手續費－證交稅。新有效成本＝起始有效成本－累計淨價差÷總股數。最高買回價＝賣出價－〔（目前有效成本－目標成本）×總股數＋本次費用〕÷操作股數。

只適用現股賣出後買回相同股數、每筆操作後持股總數不變的情況。不含加碼、減碼、股利、融資、融券或拆併股。有效成本是策略追蹤值，可能為負數，也不等於券商帳上成本。

此工具僅做數學試算，不包含即時股價或買賣建議。股數必須為整數；張數可用小數輸入零股等值。成本降低不代表持股市值上升。
